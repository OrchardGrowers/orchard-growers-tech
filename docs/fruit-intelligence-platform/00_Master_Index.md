# Architecture Rules

Every future feature must satisfy the following:

- No breaking API changes.
- No silent modification of Grower data.
- Inspection results remain independent from user-entered values.
- AI recommendations never become final decisions automatically.
- Every AI decision should be explainable whenever possible.
- Every inspection should remain versioned.
- Every future hardware implementation must remain compatible with this architecture.
